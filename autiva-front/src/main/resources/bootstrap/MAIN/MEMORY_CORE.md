# 核心记忆

此文件每次会话都会注入上下文窗口。保持简洁（≤80行）。
详细的记忆文件存储在 memories/ 目录中，通过 MEMORY_INDEX.md 索引。

## 记忆行为规则
- 回答关于用户偏好、历史事件、人际关系的问题前，先搜索记忆（MemoryView 或 MemorySearch）
- 了解到关于用户的新信息时，主动保存为记忆（MemoryCreate）
- 用户纠正了你的行为时，必须保存为 feedback 类型记忆
- 发现记忆过时时，及时更新（MemoryStrReplace）
- 记忆是你在会话间持续存在的方式——认真对待它
