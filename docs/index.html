概览 · OVERVIEW

一个能在使用中持续改进的本地智能体。

Autiva 不只是一个聊天框。它把执行日志沉淀为经验，把经验驱动基因突变、路由更新与规则沉淀，再用 JGit 版本化固化——形成自我进化的闭环。

本地优先

智能体定义、会话、记忆、基因全部存于 ~/.autiva/，数据不出本机。JGit 管理基因版本，可随时 diff 与回滚。

自我进化

GeneOS 三层架构：基因执行 → 经验提取 → 进化决策。表观遗传值基于历史成功率动态调整，越用越聪明。

可扩展工具

30+ 内置工具覆盖文件、搜索、命令、交互、任务、定时、记忆与 MCP。AbstractTool + Toolkit 模式，一个工具一个类。

核心能力 · CAPABILITIES

六个模块，协同驱动智能体。

从统一 Agent 模型到 A2UI 声明式界面，从自进化引擎到两层记忆，每个模块都为"越用越聪明"这一目标服务。

统一 Agent

UNIFIED AGENT MODEL

主智能体与子智能体同为 Agent 实例，区别仅在 AgentDefinition 配置。纯 POJO 设计，依赖通过 RuntimeContext 运行时传递。

  • Builder 方法链启用可选能力
  • 基于 Spring AI Advisor 拦截
  • 子智能体内置不可配置

自进化引擎

GENEOS · EVOLUTION

基于 GeneOS 三层架构：基因执行层、经验引擎层、进化引擎层。基因可突变、路由可更新、规则可沉淀。

  • 表观遗传动态权重
  • JGit 基因版本仓库
  • 金丝雀检查 + 安全防护

工具系统

30+ BUILT-IN TOOLS

AbstractTool<I> + Toolkit 模式，统一 ToolResult 返回。AutivaToolCallingManager 实现工具校验与权限控制，LLM 幻觉工具名时友好降级。

  • 跨平台 Shell 抽象
  • MCP 客户端集成
  • 白名单注册机制

技能系统

SKILL · KNOWLEDGE

SKILL.md + YAML frontmatter 定义专业知识技能。支持 ZIP 导入、文件系统 / JAR / 类路径多来源加载，技能信息注入系统提示词。

  • 动态加载与重载
  • ZIP / URL 导入
  • MarkdownParser 解析

A2UI 动态界面

AGENT-TO-UI v0.9.1

声明式动态 UI 生成协议。Agent 通过 A2UITool 创建 Surface、更新组件、更新数据模型，用户交互回流为事件触发新一轮推理。

  • 邻接列表组件模型
  • 事件 / 函数调用双轨
  • 验证规则与禁用逻辑

进化闭环 · EVOLUTION LOOP

执行 → 经验 → 进化 → 固化。

每次执行都被记录、提取为经验、驱动进化决策，再经金丝雀检查与 JGit 提交固化，最终在下次执行中改进。这是一个真正闭环的自我改进系统。

STEP 01
基因执行
GeneRuntime 分发到 Shell / Java / Strategy 执行器
STEP 02
执行记录
ExecutionRecorder 写入 logs/executions/*.jsonl
STEP 03
经验提取
LLM 从日志挖掘失败模式与根因，置信度 ≥ 0.7
STEP 04
进化决策
基因突变 + 路由更新 + 规则沉淀
STEP 05
JGit 提交
金丝雀检查通过后，GeneRepository 版本化固化
STEP 06
下次改进
表观遗传增强，连续成功 ≥3 次生成胶囊

快速开始 · QUICK START

三步启动你的 Autiva。

克隆仓库、构建产物、运行桌面端。首次启动会从种子基因初始化 ~/.autiva/ 目录。

1
克隆仓库
# 克隆并进入项目
git clone https://github.com/botloom/IdeaForge.git
cd autiva
2
构建产物
# 构建 desktop 模块
mvn -pl autiva-desktop -am \
  clean package -DskipTests
3
运行桌面端
# 启动 Autiva 桌面端
java --enable-native-access=javafx.graphics \
  -jar autiva-desktop/target/autiva-desktop-*.jar
提示：需要 JDK 25 与 Maven。首次运行会从 classpath:evolve/genes.seed.json 初始化 4 个种子基因到 ~/.autiva/evolve/genes/。在 ~/.autiva/settings.properties 中配置模型 API Key 后即可开始对话。
