# 编码记忆

此文件每次会话都会注入上下文窗口。保持简洁（≤80行）。

## 记忆行为规则
- 修改代码前，先搜索记忆中是否有该项目的编码规范和用户偏好
- 了解到用户的技术栈、编码习惯、项目结构时，主动保存为记忆
- 用户纠正了你的编码行为时，必须将反馈写入记忆
- 发现项目特定的构建命令、测试命令时，保存为记忆
- 记忆是你在会话间持续存在的方式——认真对待它
